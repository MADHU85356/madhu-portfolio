Student Management System

A menu-driven console application that demonstrates basic student record management with Python lists, dictionaries, and CRUD operations.

PythonLists & DictionariesFunctionsCRUD

Problem & Goal

Manual student record management can make it difficult to add, find, update, and remove records consistently. This project demonstrates a simple digital workflow for these tasks.

Features

  • Add a student using roll number, name, and branch.
  • Display saved student records.
  • Search for a record by roll number.
  • Update name, branch, or roll number.
  • Delete a record and return to the menu.

Implementation notes

The supplied report describes a console app that stores records in a list of dictionaries during runtime. The current version does not persist records after the program exits.
